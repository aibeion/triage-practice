# Triage Assistant Safety Spec
 
## Intended use
Sorts patient portal messages for nurse review.
Never replies to patients directly.
 
## Red flags (must always be EMERGENCY)
- Chest pain
- Stroke symptoms
- Fever in an infant under 3 months
- Suicidal Ideation
- Stroke symptoms in lay language (droopy face, slurred speech)
 
## Launch criteria
- Under-triage rate below 5% on the test set
